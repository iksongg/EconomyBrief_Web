# Empty & Error States

Source: Figma "디자인시스템" (Design System) board, section **13. Empty & Error States**.

> "잘 될 때"만 있던 화면에 "안 될 때"를 채웁니다. 아이콘 + 제목 + 설명 + 버튼(선택) 구조를 고정합니다.
> (Fills in the "when it doesn't work" case for screens that only had a "when it works" state. The structure is fixed: icon + title + description + optional button.)

## The 4 State Cards

| Icon | Title | Description | Button |
|---|---|---|---|
| `icon/line/search` | 검색 결과가 없어요 (No search results) | 다른 키워드로 다시 검색해보세요 (Try searching with a different keyword) | 검색어 지우기 (Clear search) |
| `icon/line/notifications` | 네트워크에 연결할 수 없어요 (Can't connect to the network) | 인터넷 연결을 확인하고 다시 시도해주세요 (Check your internet connection and try again) | 다시 시도 (Retry) |
| `icon/line/newsmode` | 아직 저장한 기사가 없어요 (No saved articles yet) | 관심있는 기사를 도토리 아이콘으로 저장해보세요 (Save articles you're interested in with the acorn icon) | 뉴스피드 보기 (View news feed) |
| `icon/line/search` | 오프라인 상태예요 (You're offline) | 연결되면 최신 뉴스로 자동 업데이트돼요 (Once reconnected, the latest news updates automatically) | — (none) |
